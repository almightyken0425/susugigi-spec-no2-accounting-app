# 匯率編輯器: CurrencyRateEditorScreen

## 畫面目標

- 提供更新幣別對匯率的介面

---

## 線框圖

```text
+--------------------------------+
| [X]        Set Rate       [✓]  |
+--------------------------------+
|                                |
| [ From Cur ]      [ To Cur ]   |
|                                |
| [ Amount A ]  =  [ Amount B ]  |
|                                |
+--------------------------------+
```

---

## 佈局

### 導覽列

- Header 模式: C
- 關閉按鈕
- 設定匯率 標題
- 完成按鈕
  - **IF** 輸入欄位未填妥:
    - 不可點按

### 幣別對顯示區

- 來源幣別代碼
- 目標幣別代碼
- 來源幣別鎖定為主要貨幣，不可修改
- 目標幣別由匯率列表點選的幣別對帶入，不可修改

### 匯率輸入區

- 來源金額輸入框
  - 預設值 1
  - 依輸入欄位共用政策
  - 即時只接受數字字元與單一小數點，其餘輸入不更新
  - 使用者輸入上限為 15 字元，小數點計入字元數
  - 新增字元超過上限時即時阻擋，輸入不再更新
- 等號標籤
- 目標金額輸入框
  - 預填 1 單位主要貨幣對應的外幣數量
  - 預填以一般小數完整顯示，不使用科學記號，不截斷或自動捨入
  - 預填可超過 15 字元，允許使用者逐步縮短或修改
  - 依輸入欄位共用政策
  - 即時只接受數字字元與單一小數點，其餘輸入不更新
  - 使用者輸入上限為 15 字元，小數點計入字元數
  - 新增字元超過上限時即時阻擋，既有超長預填仍可縮短或等長修改

---

## 互動

- **點按關閉按鈕:**
  - 返回上一頁

- **點按完成按鈕:**
  - **IF** 兩欄與預填相同:
    - 返回上一頁，不新增匯率紀錄
  - **ELSE IF** 任一欄位仍超過 15 字元:
    - 顯示包含小數點的字元上限提示，阻擋儲存，保留輸入供使用者決定精度
  - **ELSE:**
    - 呼叫 createCurrencyRate
  - **IF** 已呼叫操作且成功:
    - 返回上一頁
  - **IF** 已呼叫操作且失敗:
    - 顯示錯誤提示
