# 搜尋: SearchScreen

## 畫面目標

- 提供搜尋所有交易與轉帳備註的介面，並作為導航至紀錄編輯畫面的入口

---

## 觸發情境

- 以 Modal 呈現
- 由點擊首頁搜尋入口觸發

---

## 線框圖

```text
+----------------------------------+
| [X]         搜尋                 |
+----------------------------------+
| .------------------------------. |
| | [Icon] Category     Amount   | |
| |        Note(hl)         Date | |
| |------------------------------| |
| | [Icon] From > To [⟳] Amount  | |
| |        Note(hl)         Date | |
| '------------------------------' |
+----------------------------------+
| [ Search...                    ] |
+----------------------------------+
```

---

## 佈局

### 導覽列

- Header 模式: D
- 關閉按鈕
- 搜尋 標題

### 搜尋輸入區

- Search 模式: Bottom Pill

### 搜尋結果區

- List 模式: Custom
- 含關鍵字 highlight、雙列佈局
- 視覺對齊對側 Design git 的 TX_LIST_TOKENS 群組
- **IF** 搜尋框為空:
  - 顯示 "輸入關鍵字以搜尋交易" 提示
- **IF** 無符合結果:
  - 顯示 "找不到結果" 提示
  - 副標回顯當前搜尋關鍵字
- 搜尋結果列表
  - 外層由群組卡片包覆
  - row 間以 hairline 分隔線分隔
  - 交易與轉帳各自最多顯示 50 筆
  - 依日期由新至舊排序
  - 排除所屬帳戶或分類已停用的紀錄
    - **IF** 交易所屬帳戶或所屬分類已停用:
      - 不列入結果
    - **IF** 轉帳來源帳戶或目的帳戶已停用:
      - 不列入結果
    - 停用紀錄較多時，結果可能少於各自 50 筆上限
- **單筆紀錄列:**
  - 雙列佈局
  - **上列:**
    - 左：圖示置於 outline 框內
      - 交易：類別圖示
      - 轉帳：轉帳圖示
      - 圖示一律採主色，不依收支正負著色
    - 中：
      - 交易：類別名稱
      - 轉帳：來源帳戶名稱 → 目的帳戶名稱，中間以方向箭頭分隔
    - 右：金額
  - **下列:**
    - 左：備註
    - 右：日期，使用 App 設定的時區，與首頁紀錄列及編輯器一致
  - 金額顯示:
    - 一律採主文字色，不依收支正負著色
    - 交易收入：不顯示正負號
    - 交易支出：於幣別符號與數字之間顯示負號
    - 轉帳：不顯示正負號，屬帳戶間移動、無單一收支方向
    - 跨幣別轉帳：並列顯示來源金額 → 目的金額
    - 同幣別轉帳：顯示單一金額
  - **IF** 該筆為定期排程實例:
    - 金額左側並列循環圖示
    - 圖示使用停用態前景色，視覺權重低於金額
    - 圖示本身不獨立觸發互動，點按列的行為與一般紀錄相同

---

## 互動

- **點按關閉按鈕:**
  - 關閉 Modal

- **輸入搜尋文字:**
  - 輸入後 debounce 自動觸發搜尋，更新搜尋結果列表

- **返回此畫面時:**
  - **IF** 搜尋框非空:
    - 重新執行搜尋，反映編輯畫面可能造成的資料變動

- **復原完成時:**
  - 監看 UndoLogic 的復原完成計數
  - **IF** 搜尋框非空:
    - 重新執行搜尋，反映復原後的資料狀態

- **點按搜尋結果列表項目:**
  - **IF** 交易紀錄:
    - 導航至 TransactionEditorScreen
  - **IF** 轉帳紀錄:
    - 導航至 TransferEditorScreen
